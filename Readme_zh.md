## -- 仓库简介
本仓库归档系列深度产业研判文稿（J06-EX系列），围绕**AI产业链下游、独立大模型商业宿命、算力负债、行业出清周期、AI生态范式**展开闭环推演。
不局限于表层估值泡沫叙事，从算力负债、资本公理、互联网产业历史规律、生态底层范式，推导AI产业中长期演化路径、玩家分层、企业宿命与时间窗口。

> 核心总论点摘要：
> 1. 无自有业务底盘、无终端场景、无交付能力的纯独立大模型企业具备**结构性不可持续性**，将在**18-30个月募资周期**内迎来估值重估与系统性行业出清；
> 2. 低价残值并购是纯模型企业最优归宿，尾部项目将直接清算；
> 3. AI不是全新范式革命，是互联网上层能力延伸；互联网长期护城河是生态底盘，而非单点技术；
> 4. 当前整个AI行业尚处于**工具层阶段，尚未形成真正意义上的生态**；真正AI生态根植于「群体统一行为范式」，分为开发者工程范式生态、垂直场景人-AI共生生态两大方向。

## -- 核心公理体系
1. **算力负债公理**：纯大模型企业不是轻资产软件公司，是算力长期锁仓的**分期刚性负债主体**，营收浮动、成本刚性，天然规模不经济。
2. **资本壁垒公理**：大模型没有永久技术护城河，技术领先仅为6-12个月时间差；真正门槛是资本、算力、电力。
3. **中间层终局公理**：产业革命终局消灭中间层；只售卖模型API、无终端场景底盘的中间层厂商，终将被挤压出市场。
4. **生态底层公理**：生态是大量参与者自发沉淀的统一行为范式；工具、产品、流量不等于生态。当前AI只有工具，尚未形成生态。

## -- 关键时间预判（数据基准：2026-09-01）
- 行业系统性出清窗口：**18-30个月新一轮募资周期**
- 2026下半年-2027集中IPO本质：算力远期负债的二级市场债务展期，不改变底层结构性矛盾
- 纯模型企业生死转型窗口期：未来24个月，必须完成自有业务/场景底盘搭建，否则面临估值重估、现金流断裂、并购或清算
